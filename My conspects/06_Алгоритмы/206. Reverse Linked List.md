> [!task] Task
> Given the `head` of a singly linked list, reverse the list, and return _the reversed list_.

**Example 1:**

**Input:** head = [1,2,3,4,5]
**Output:** [5,4,3,2,1]

**Example 2:**

**Input:** head = [1,2]
**Output:** [2,1]

**Example 3:**

**Input:** head = []
**Output:** []

**Constraints:**

- The number of nodes in the list is the range `[0, 5000]`.
- `-5000 <= Node.val <= 5000`

### Код:

```python
# Definition for singly-linked list.
# class ListNode(object):
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution(object):
    def reverseList(self, head):
        """
        :type head: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        prev = None
        cur = head
        
        while cur:
            old_next = cur.next
            cur.next = prev
            prev = cur
            cur = old_next
        
        return prev

```
### Важные моменты:
- Нужно работать начиная с головы, а не предварительно выставлять `prev = head & cur = head.next`
